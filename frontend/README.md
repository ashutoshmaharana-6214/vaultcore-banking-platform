# VaultCore Frontend — React + TypeScript

Milestone 1: responsive application shell, routing, API configuration and a live **read-only** backend health probe. No fabricated account balances, fake transactions or working payments.

## Prerequisites
- Node.js >= 22.12 (recommended) or >= 20.19
- npm
- Optional for backend health status: Spring Boot API running locally on port 8080

## Run locally

From the repository root:

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Open http://localhost:5173

To verify:

```bash
npm run typecheck
npm run build
```

```text
    shared/

      components/FeaturePlaceholder.tsx
    main.tsx
    styles.css
  vite.config.ts                   # Dev proxy: /api and /actuator -> 8080
```

## Integration & security notes

- The GitHub `main` backend currently represents a **single Spring Boot API starter**, not fully deployed microservices.
- Login, financial reads and writes remain intentionally unimplemented in the frontend.
- Do **not** expose an unauthenticated banking API on the public internet.
- Add account ownership authorization, authentication/session strategy, input validation, transaction idempotency, audit trails and tests before public staging access.
- `VITE_*` values are bundled into browser JavaScript; **never** put passwords, private keys, tokens or secrets there.
- The Vite proxy is for *local development*. Hosting needs reverse-proxy/HTTPS configuration and route fallback for client-side navigation.
- Dependency lockfile will be generated by the first `npm install`; commit it before a production build.
